---
title: Security Fix Automation
description: Vulnerability monitoring for Ghaf with flakevuln.
---

Ghaf uses [flakevuln](https://github.com/tiiuae/flakevuln) to scan configured
Nix flake outputs for known vulnerabilities. It compares the pinned
dependencies with newer nixpkgs revisions to highlight potential fixes
available through dependency updates or backports.

Daily results are available in the [Ghaf flakevuln workflow runs](https://github.com/tiiuae/ghaf/actions/workflows/flakevuln.yml),
with a summary and downloadable report artifacts for manual review.
See the [flakevuln overview](https://github.com/tiiuae/flakevuln/blob/main/doc/overview.md)
for details of the scans, comparisons, and reports.
