This is monthly Ghaf release which has been fully tested on Nvidia Orin NX, Nvidia Orin AGX, Lenovo X1 Carbon Gen11 and System76 Darter Pro platforms

## Release Tag

https://github.com/tiiuae/ghaf/releases/tag/ghaf-26.09.1

## Supported Hardware

Reference HW platforms:
* Lenovo ThinkPad X1 Carbon Gen 11
* System76 Darter Pro
* Nvidia Jetson Orin NX & AGX

Generic HW support:

* Generic x86_64 systems supporting UEFI boot and hardware virtualization
* Hardware compatibility may vary depending on graphics, networking, audio, and peripheral devices
