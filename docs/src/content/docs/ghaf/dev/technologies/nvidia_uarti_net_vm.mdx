title: NVIDIA Jetson AGX Orin UARTI Passthrough to NetVM

  label: UARTI Passthrough to NetVM
---

UARTI is `serial@31d0000` on Jetson AGX Orin and is exposed through the debug
Micro-USB connection as `ttyACM1` at 115200 baud.

The in-tree UARTI composition is an experimental QEMU-only diagnostic path. All
exported Orin targets now default to Crosvm, so using UARTI requires an explicit
NetVM rollback:

```nix
{
  ghaf = {
    hardware.nvidia.passthroughs.uarti_net_vm.enable = true;
    virtualization.vmConfig.sysvms.netvm.vmm = "qemu";
  };
}
```

The module binds `31d0000.serial` to `vfio-platform`, applies the host
device-tree overlay, and supplies NetVM with the QEMU device tree and serial
console arguments. It is disabled by default and is not covered by the Crosvm
Orin regression matrix.

To inspect the NetVM console, connect the debug Micro-USB port and run:

```sh
picocom -b 115200 /dev/ttyACM1
```

For connector details, see
[NVIDIA Jetson AGX Orin: UART Passthrough](/ghaf/dev/technologies/nvidia_agx_pt_uart).
