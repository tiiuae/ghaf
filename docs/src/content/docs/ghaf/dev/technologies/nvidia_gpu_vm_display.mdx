The example compositions for split `gpu-vm`/`disp-vm` and combined `gui-vm`
GPU and display passthrough are maintained in the
[Ghaf GPU partitioning examples repository][examples]. Ghaf provides the
generic VM, device-manager, and Jetson platform mechanisms consumed by those
examples.

See the examples repository's [architecture][architecture] and
[user guide][user-guide] for topology, build, flash, and runtime details.
