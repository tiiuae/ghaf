The CUDA Green Context manager is maintained in the
[GPU partition manager repository][manager]. Its Orin AGX and Orin NX example
payloads, compositions, workloads, and validation tools are maintained in the
[Ghaf GPU partitioning examples repository][examples].

See the examples repository's [user guide][user-guide] for current build,
deployment, and runtime instructions.
