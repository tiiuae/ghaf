The Orin AGX and Orin NX `gpu-vm` example composition is maintained in the
[Ghaf GPU partitioning examples repository][examples]. Ghaf provides the
generic Crosvm, device-manager, and Jetson host mechanisms consumed by it.

See the examples repository's [architecture][architecture] and
[user guide][user-guide] for the current device layout, targets, and runtime
instructions.
