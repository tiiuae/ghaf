Ghaf provides the reusable Orin AGX and Orin NX `gpu-vm` composition and the
generic Crosvm and device-manager integration. Jetpack-nixos provides the
Jetson host and guest mechanisms consumed by it. The
[Ghaf GPU partitioning examples repository][examples] layers the container
runtime, partition manager, probes, and workloads onto this VM.

See the examples repository's [architecture][architecture] and
[user guide][user-guide] for the current device layout, targets, and runtime
instructions.
