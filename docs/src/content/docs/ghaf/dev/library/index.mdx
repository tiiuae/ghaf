---
title: Ghaf as a Library
---

Ghaf is a framework for creating virtualized edge devices. Downstream projects import it as a flake
input and declare a derived system on top of it, rather than forking the tree.

![Ghaf Usage Overview](@assets/ghaf/usage_overview.drawio.png "Your project and example inputs from Ghaf and other repositories")

The Ghaf Platform repository provides declarative modules and reference implementations. External
repositories supply hardware options, image generators and reference board-support packages.

To create, build and update a project, follow
[Downstream Project Setup](/ghaf/dev/guides/downstream-setup); the builder arguments it uses are
listed in [Builder Functions](/ghaf/dev/ref/builder-functions).

This section documents the module and option API those projects consume:

- [Global Config](/ghaf/dev/global-config) — settings propagated from the host into every VM
- [Module Options](/ghaf/dev/library/modules_options) — the generated `ghaf.*` option reference
- [VM Helpers](/ghaf/dev/library/vm-helpers) — `lib.ghaf.vm.*`
- [Features API](/ghaf/dev/library/features-api)
- [Profiles API](/ghaf/dev/library/profiles-api)
